kを置く場所と表現できる図形

方程式 k(A) + B = 0 は、交点を通る図形群のうち 「A = 0 だけは表現できない」 という性質があります（k をどんな値にしても完全には A=0 に重ねられないため）。

  • k(A) + B = 0： k = 0 のとき B = 0 に完全一致。k を大きくすると A = 0 に近づく。
  • A + k(B) = 0： k = 0 のとき A = 0 に完全一致。k を大きくすると B = 0 に近づく。

ラジオボタンで k の位置を切り替えることで、どちらの図形が「再現できない例外」になるかを視覚的に実験できます。
