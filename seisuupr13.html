整数問題（Pr13）

条件: a < b < c かつ 1/a + 2/b + 3/c = 2

変数操作 (1〜10)

順序エラー: a < b < c を満たしていません
1/a = 1.0000
2/b = 1.0000
3/c = 1.0000

可視化と判定

未成立
1/1 + 2/2 + 3/3 = 3/1 (≈ 3.0000)
惜しい！目標値「2.0」に非常に接近中！

発見した解

0 / 0 発見
数学的ヒント (絞り込みの手順)

不等式で範囲を絞り込むと効率よく発見できます：

  1. a の限定:
    a < b < c より、1/a + 2/b + 3/c < 1/a + 2/a + 3/a = 6/a。
    6/a > 2 ⟹ a < 3 となり、a = 1 または 2 に限定されます。
  2. a = 1 のとき:
    2/b + 3/c = 1 ⟹ 5/b > 1 ⟹ b < 5。
    a < b より b = 2, 3, 4 の候補に絞られます。
  3. a = 2 のとき:
    2/b + 3/c = 3/2 となり、同様に b, c の値を決定できます。
